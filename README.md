# working-cars-maze

はたらくくるまが好きな子ども向けの、スマホ / iPad で遊べる迷路アプリです。

https://aew2sbee.github.io/working-cars-maze/

## Development

```sh
npm install
npm run dev      # http://localhost:4321/working-cars-maze/
npm run build
```

Every pull request gets a preview at `https://aew2sbee.github.io/working-cars-maze/pr-preview/pr-<number>/`. Changes reach `main` only through a reviewed PR.
